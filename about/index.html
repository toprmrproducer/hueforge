About HueForge

HueForge does one thing: it turns a single color into a complete, usable palette, entirely inside your browser. There's no account to create, no upload to wait on, and no server that ever sees the color you pick.

We built it as a single-purpose tool on purpose. Rather than bundling a dozen unrelated utilities behind one confusing homepage, HueForge is exactly, only, a color palette generator — so it loads fast, stays focused, and does the one job well.

How it works

When you type a hex code or use the native color picker, HueForge converts that color to HSL (hue, saturation, lightness) and rotates the hue around the color wheel to derive three classic palette types: a complementary color 180° away for maximum contrast, two analogous colors 30° to either side for a harmonious feel, and two triadic colors 120° apart for a balanced three-color scheme. Every hex, RGB, and HSL value shown is computed with plain JavaScript color math — there is no server round-trip and no external color API involved.

You can also extract a palette straight from an image. Drop in any photo and HueForge draws it onto an off-screen canvas, samples the pixels, and groups them with a small k-means pass to surface the dominant colors — then exports them as CSS variables, JSON, or a downloadable PNG swatch strip. Like everything else, the image is read locally and never uploaded.

Because everything happens on your device, nothing you pick is ever transmitted, logged, or stored anywhere. Close the tab and it's gone, exactly as if you'd never opened it.

Why it's free

HueForge is supported by small, unobtrusive advertising rather than subscriptions or paywalls. There's nothing to sign up for and no limit on how many palettes you generate.

Every palette is generated locally in your browser. Nothing you pick is ever sent to a server.
